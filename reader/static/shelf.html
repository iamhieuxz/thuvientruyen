Cách thêm truyện mới

Mỗi truyện là một thư mục con trong data\, file chương đặt tên 0001_Tên chương.md. Kèm book.json và cover.jpg nếu muốn:

data\tieu_su_truyen\book.json
{ "title": "Tên truyện", "author": "Tác giả",
  "desc": "Giới thiệu ngắn", "cover": "cover.jpg" }

Kệ sách tự quét lại — không cần khởi động lại server.
